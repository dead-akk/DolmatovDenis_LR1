# Calculator

Desktop-калькулятор на WPF (.NET Framework 4.7.2) с обычным и
инженерным режимами, историей вычислений, логированием действий и
переключаемыми цветовыми темами.

## Установка

Требования:
- Windows;
- Visual Studio 2019 или новее с компонентом «Разработка классических
  приложений .NET»;
- .NET Framework 4.7.2 (Developer Pack).

Шаги:

```bash
git clone https://github.com/{username}/{MyProject}.git
```

1. Откройте `Calculator.sln` в Visual Studio.
2. Дождитесь восстановления зависимостей.
3. Соберите решение (`Build → Build Solution`).

## Использование

1. Запустите проект (F5) – откроется окно обычного калькулятора.
2. Вводите числа и операции кнопками или переключайте режим
   переключателем «Обычный / Инженерный» в верхней части окна.
3. Кнопка **Hist** показывает последние 15 вычислений и позволяет
   очистить историю.
4. Выпадающий список в правом верхнем углу переключает тему
   оформления (Тёмная / Светлая / Серая / Неоновая).

## Структура проекта

```
Calculator/
├── App.xaml / App.xaml.cs      – точка входа приложения
├── Views/                      – представление (окна)
│   ├── MainWindow.xaml(.cs)    – обычный калькулятор
│   └── Window1.xaml(.cs)       – инженерный калькулятор
├── Models/                     – модели данных
│   └── CalculatorHistory.cs    – история вычислений
├── Services/                   – бизнес-логика и сервисы
│   ├── ICalculatorLogger.cs    – интерфейс сервиса логирования
│   ├── CalculatorLogger.cs     – файловая реализация логирования
│   └── CalculatorLogic.cs      – обработка ввода и вычисления
├── Infrastructure/             – сквозная инфраструктура
│   └── ThemeManager.cs         – применение цветовых тем
└── Properties/                 – сведения о сборке, настройки
```

### Назначение модулей

- **Views** – окна и элементы управления. Не содержат бизнес-логики,
  делегируют обработку событий в `Services`.
- **Models** – данные приложения (история вычислений).
- **Services** – вычисления, разбор выражений, математические
  функции, логирование. Не зависят от конкретного окна – принимают
  `TextBox` дисплея как параметр.
- **Infrastructure** – сквозные механизмы, не относящиеся напрямую
  к предметной области калькулятора (переключение тем оформления).

Пространства имён (`Calculator.Views`, `Calculator.Models`,
`Calculator.Services`, `Calculator.Infrastructure`) соответствуют
структуре каталогов.

## Данные

Приложение не использует базу данных и внешние API. Оно работает с
двумя видами данных, оба – локальные:

- **История вычислений** – хранится в памяти на время работы
  приложения (`Models/CalculatorHistory.cs`), не сохраняется на
  диск и очищается при перезапуске или кнопкой Hist.
- **Журнал действий** (`log.txt`) – создаётся рядом с исполняемым
  файлом при запуске, содержит построчный лог действий пользователя
  с отметками времени. Файл генерируется автоматически, в
  репозиторий не попадает (исключён в `.gitignore`).
